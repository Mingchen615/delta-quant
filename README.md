## 核心哲学

> **金额最大化**：赢的单子跑到极致R:R 5:1+，亏的单子3分钟内必须砍

### 交易规则

- **杠杆**: 基础20x，信号强+5x，最高50x
- **止损**: 硬止损-25%，时间止损3分钟，软止损-5%
- **止盈**: 动态追踪，2R→3R→5R+
- **风控**: 单笔≤3%，日亏≤5%，回撤≤20%
- **持仓**: 最多同时2个仓位

## 13个Agent详解

### 数据采集层 (5个)

| Agent | 功能 | 间隔 |
|-------|------|------|
| NewsAgent | 抓取CryptoPanic新闻，分析情绪 | 60s |
| WhaleAgent | 监控>50万USDT大额成交 | 5s |
| CorrelationAgent | 计算BTC相关性、板块轮动 | 5min |
| OrderFlowAgent | 分析订单簿买卖压力 | 3s |
| RegimeAgent | 判断趋势/震荡/高波动 | 60s |

### 分析决策层 (3个)

| Agent | 功能 | 输入 |
|-------|------|------|
| SignalAgent | 9因子评分扫描Top40 | 市场数据 |
| DebateAgent | DeepSeek多空辩论 | SignalEvent |
| DecisionAgent | 计算杠杆、仓位参数 | Signal + Debate |

### 风控执行层 (3个)

| Agent | 功能 | 检查项 |
|-------|------|--------|
| RiskAgent | 单笔/日风险/回撤检查 | 3项全过 |
| PortfolioAgent | 多仓位、相关性检查 | ≤2仓位 |
| ExecutorAgent | 市价下单、滑点控制 | 执行确认 |

### 持仓复盘层 (2个)

| Agent | 功能 | 策略 |
|-------|------|------|
| PositionAgent | 三级止损+动态止盈 | 1s检查 |
| ReviewAgent | 交易记录、统计分析 | 日报 |

## 安装

### 环境要求

- Python 3.10+
- pip

### 安装步骤

```bash
# 克隆或下载项目
cd delta-quant

# 安装依赖
pip install -r requirements.txt
```

### 配置

编辑 `config/settings.py` 或设置环境变量：

```bash
# 币安API (可选，不填则只能用模拟盘)
export BINANCE_API_KEY="your_api_key"
export BINANCE_API_SECRET="your_api_secret"

# DeepSeek API (可选，不填辩论用默认结果)
export DEEPSEEK_API_KEY="your_deepseek_key"

# CryptoPanic API (可选)
export CRYPTOPANIC_API_KEY="your_cryptopanic_key"
```

## 信号评分 (9因子)

```
总分 = Σ(因子分数 × 权重) × 100

权重分配:
├── 趋势 (EMA交叉)      20%
├── 动量 (RSI+MACD)     15%
├── 波动率 (布林+ATR)   10%
├── 成交量              15%
├── 持仓量变化          10%
├── 资金费率             5%
├── 清算信号            10%
├── 多时间框架          10%
└── 新闻情绪            5%
```
